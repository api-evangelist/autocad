More Webhook Events for Issues API: Track Comments and Attachments xiaodong.liang… 8 Oct 2026 Xiaodong Liang Share Autodesk Forma Issues API now supports more Webhook events, making it easier to build integrations that stay up to date with changes to issues and their related objects. In previous versions, the Issues API provided webhook events for issue creation, updates, and deletion etc. With this release, webhook support is extended to changes to objects associated with an issue, including comments and attachments .
